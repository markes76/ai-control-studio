# Product

AI Control Studio is a local native macOS workspace for gateway routing, MCP registration, Claude Code definitions, optional decision mods and Keychain-backed credential references.

It is practical and elegant, with a pixel workshop visual identity. Preserve native keyboard behavior, readable configuration forms and explicit installation/authorization steps. Client files remain authoritative. New installations have neutral defaults and no organization-specific endpoint or credential.

The platform is not yet centralized enterprise administration. Future priorities include global search, ownership/provenance, shared transaction locking and signed distribution.
