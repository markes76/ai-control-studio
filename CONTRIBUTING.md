# Contributing

Open an issue describing the problem or proposed change. Keep changes focused and preserve the existing Mac utility identity.

Run the Python tests, JavaScript checks and macOS build before sending a pull request. Use synthetic data and temporary files for tests. Do not use personal API keys, organization URLs, customer files or real client configuration as fixtures. Never commit build outputs, local state, credential references or backups.

For client integrations, link current primary documentation and distinguish configured, enabled, authenticated and connected states. Preserve unrelated settings and add meaningful tests for writes, rollback, consent and failure behavior.
